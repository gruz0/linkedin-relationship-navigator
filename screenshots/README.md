# Common Ground screenshots

This directory contains six Common Ground screenshots captured from Alexander Kadyrov’s own LinkedIn export in September 2026, plus two reviewed screenshots that explain how to request an archive from LinkedIn.

Privacy mode was enabled for every Common Ground capture. The aggregate counts, normalized roles, relationship classifications, message counts, and dates are real. Names, companies, raw titles, locations, annotations, profile links, and message content are masked by the application.

The original archive is private and is not part of this repository. The public fictional demo remains available for anyone who wants to explore the complete product without uploading an archive.
